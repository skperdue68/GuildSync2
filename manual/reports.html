Reports and settings

The Reports tab answers officer questions; the Admin tab holds the switches that change how GuildSync behaves.

What each report is for

ReportUse it to
Member LinksReview candidates, blocks and confirmed links, and fix them. See Member links.
Discord Rank AuditFind Discord members whose rank role does not match their ESO rank.
Associate Ticket ReportCheck raffle tickets held by Associates.
Last SeenFind members who have not been seen recently, filtered by link status.
Community HighlightsRaffle regulars, guild trader leaders and Discord activity. The same data as /highlights.
Community StatisticsMembership and participation trends over time.

Reports open in place, keep their scroll position while data refreshes, and can be closed with Escape or the close button.

Rank audit

The rank audit compares each linked pair: the member's ESO rank against the Discord role they hold. Members whose linked ESO account has left the roster are deliberately left out, so they do not clutter the list with a rank they no longer have.

Community Highlights and statistics

Highlights ranks raffle participation, guild trader sales and Discord activity. Trader gold values are never included, so a big sale does not dominate the ranking. Statistics cover membership numbers and how they change over the covered period.

Raffle Bonus Tickets

This section holds the early purchase bonus rules. Everyone approved can open it and read the current settings; only Admins can change them.

  • Choose a raffle type, or one raffle, and edit its periods and percentages.
  • Save Bonus Settings applies your changes; closing the section does not.
  • Return to default restores the inherited policy for the whole configuration; Return to raffle default restores the saved policy for one raffle.
  • Saving refreshes the bonus columns and totals in the Banking tab.

Administrator Configuration

The Admin tab groups settings by function, with onboarding and raffle announcements split into smaller sections. Each setting has its own card explaining what it does, its configuration key, whether the value is Default or Overridden, and its controls.

  • Edit a field directly and choose Save Configuration. There is no override checkbox.
  • Return to default marks an override for removal; it takes effect when you save.
  • Two-choice settings mark the inherited option, such as Enabled (Default).
  • Settings apply without restarting the backend or the bot. An offline bot uses the saved settings when it reconnects.

Users who are not Admins can read every value and its default, and can refresh, but cannot change or save anything.

GuildSync users

Admins manage accounts through Manage GuildSync Users in the profile menu. A numbered circle shows how many accounts are waiting for approval. Approve accounts, set roles, and review profiles there. New accounts await approval as Viewers.

Act as account lets an Admin see GuildSync exactly as another approved person does, including which notes they can read. Return to my account ends it, and so does logging out.

How refreshes behave

Background updates replace only what changed: rows update, new entries appear, removed entries disappear, and your filters, sorting, scroll position and unsaved edits survive. Clicking a tab reloads that tab's full dataset.
