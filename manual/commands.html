Commands

Two command sets, in two different places: slash commands in Discord, and chat commands inside ESO.

Read this first. In Discord, /gsr is the raffle command. In ESO, /gsr is the roster add-on. They are unrelated. GuildSync commands in ESO belong to the add-ons; Discord commands belong to the bot.

Discord: for everyone

These work for any member of the server. Text after a colon is an option you type.

CommandWhat it does
/highlightsCommunity Highlights: raffle regulars, trader leaders and Discord activity. Trader gold is excluded.
/highlights public:trueThe same report, posted visibly in the channel.
/rafflePrivately shows the current Bi-Weekly and 50/50 raffles: prizes, tickets, draw times, any early purchase bonus, and each period's latest recorded transaction.
/raffle public:truePosts the raffle summary visibly.
/raffle tickets:trueThe same ticket lookup as /tickets.
/ticketsPrivately shows the raffle summary and your own purchases for your linked ESO account.

Discord: trader invoices

GuildSyncTrader records your trader sales; the bot can send you the invoice for each one by direct message.

CommandWhat it does
/trader onSend me an invoice for each of my trader sales. /trader register does the same.
/trader offStop sending me trader sale invoices. /trader unregister does the same.
/trader salesShow your latest trader sales.
/trader sales item:<text>Show every recorded sale of an item. Any part of the item name works, spaces included.
/trader sales count:<number>Limit how many sales are listed.

Discord: raffle administration

Requires the Discord role named exactly Consigliere. /gsr is a shorter name for /gsraffle.

CommandWhat it does
/tickets verify:AccountNamePrivately checks current tickets for an ESO account. Enter the account name only: no @, mention or link.
/raffle verify:AccountNameThe same officer lookup.
/gsr loadClear and refill the working raffle sheets from the database.
/gsr load date:092526Load the raffle containing that date from its archive.
/gsr update date:092526Save winners, attendance and other supported result fields from that archived sheet back into the database.
/gsr archiveArchive the current sheet, save its results, reset both working tabs and reload current data.
/gsr resetClear managed data and draw dates on both working tabs; database records remain.

Dates are MMDDYY; unpadded dates are accepted when unambiguous, and you confirm them. Details and the editing workflow are on the Raffles page.

Discord: applications and roles

CommandWhat it doesAccess
/rolesRefresh Discord roles and members into GuildSync.Discord defaults this to members with Manage Roles.
/gsa post name:AccountNameRepost saved application decisions matching a full or partial ESO account name to the application thread.Restrict with Discord's command permissions.
/gsa stopPause automatic application posts. Manual post still works.As above.
/gsa startResume automatic application posts.As above.
GuildSync has no built-in officer check for the /gsa commands. Use Discord's own command permissions so only the right people can run them.

Discord: membership DM campaign

For Consigliere or Kingpin. The campaign messages unlinked Discord members slowly, in alphabetical order.

CommandWhat it does
/membership-dm startStart an alphabetical campaign for eligible unlinked members.
/membership-dm pausePause new campaign messages.
/membership-dm resumeResume the saved campaign without a catch-up burst.
/membership-dm restartBuild a fresh campaign, keeping send dates and community preferences.
/membership-dm statusShow progress, the last recipient and the next attempt. Add user: for one member's send date and preference.
/membership-dm resolve user:<member> outcome:<arrived|not arrived>Record whether an uncertain message arrived, or make that member eligible again.
/membership-dm repost user:<member>Repost that member's latest stored reply in the current card format.
/membership-dm test user:<member>Send one labelled test message immediately without changing normal cooldowns.

ESO: commands typed in game

These belong to the add-ons, not the bot. Type them in ESO chat exactly as shown.

GuildSyncBanking

CommandWhat it does
/gsb or /gsb helpShow banking command help.
/gsb statusWhether collection is running, and its saved progress.
/gsb streamStart or resume collection.
/gsb stopStop collection.
/gsb dumpPrint cached matching deposits for inspection. Nothing is collected or saved.
/gsb resetRestart collection from the beginning. Existing event IDs prevent duplicates. Use only when an operator asks.
/gsb debug on / /gsb debug offExtra in-game banking output.

GuildSyncRoster

CommandWhat it does
/gsr or /gsr helpShow roster command help.
/gsr guildlistCapture the current member list and ranks.
/gsr streamStart or resume collection of roster events.
/gsr stopStop collection.
/gsr dumpPrint cached matching events without saving them.
/gsr debug on / /gsr debug offExtra in-game roster output.

GuildSyncApplications

CommandWhat it does
/gsa or /gsa helpShow application add-on help.
/gsa settingsOpen welcome-message and welcome-email settings. Create, enable, edit and save templates here.
/gsa listPrint saved application decisions.

The application add-on records accept, decline and reject decisions made through ESO's application interface. After an accepted applicant's membership is confirmed it sends a welcome mail. For an online applicant it prepares welcome text in officer chat and plays an alert; press Enter to send it. {name} in a template becomes the applicant's account name.

Making add-on data reach GuildSync

Use ESO's normal /reloadui, logout or exit so the add-on writes its file, then let the desktop client upload it. Receipt mail is the exception: close ESO completely before GuildSync writes a mail batch.
