Manual / Desktop client

Desktop client

The desktop client watches your ESO folder, uploads add-on files, and can sit in the tray all day.

Installing

PlatformNotes
WindowsRun the installer. GuildSync installs per user and adds a Start menu entry.
macOSThe package is unsigned and runs in two stages. Use System Settings → Privacy & Security → Security → Open Anyway, then finish the app and ESO AddOns folder prompts.
LinuxGTK4 and WebKitGTK 6.0 are required. Tray support follows your desktop's StatusNotifier host.
Only one client can run at a time. Launching GuildSync again brings the running window back instead of starting a second copy, which would fight over the sign-in callback and the file watchers.

The window

  • The title bar has its own minimise, maximise and close buttons.
  • GuildSync remembers its size and position between launches.
  • Minimising is a normal minimise. Closing follows your tray setting below.

Tray and minimize to tray

Where your desktop provides a tray, GuildSync keeps an icon there with Show, Hide and Quit GuildSync.

  • Windows: click or double-click the icon to restore the window; right-click for the menu.
  • macOS: the menu-bar icon opens the same menu; reopening from the Dock also restores the window.
  • Linux: the icon appears when a StatusNotifier panel host is registered. Without one, GuildSync runs as a normal window and closing quits.

Minimize to tray is on by default where a tray exists, so closing the window hides it instead of quitting. The switch sits in your profile menu directly under Start GuildSync at login, and only appears when the session actually has a tray. Turn it off and closing the window quits GuildSync.

Start GuildSync at login

In the profile menu, switch Start GuildSync at login on. GuildSync registers a login item for your account:

  • Windows: a per-user entry in Run.
  • macOS: a LaunchAgent for the application bundle.
  • Linux: an XDG autostart entry.

At login GuildSync starts hidden in the tray instead of opening a window over your desktop. Click the tray icon when you want the window. If your desktop has no tray host, the window opens normally, because a hidden app with no tray would be unreachable.

The login item stores the location of the app. When GuildSync is updated or moved, it repairs that entry the next time it starts, so login keeps working. Turning the switch off removes the entry.

Your profile menu

Click your Discord avatar to open it. Alongside your name, role and client version it holds collapsible sections:

SectionWhat it does
Guild ToolsShortcuts to the tools your role can use.
SavedVariables & File WatchWhich add-on files GuildSync uploads, and the folder it watches. This is also where you open User Settings.
UpdatesThe installed version, Check for updates, and the download and release notes when a newer build exists.
VoiceThe global voice-mute shortcut and its separate unmute key.
Switch AccountAdministrators can act as another account to check what that person sees, then return.

Above the sections sit the two desktop switches, Start GuildSync at login and Minimize to tray, each shown only where the host supports it. At the bottom are Help, User Settings and Log out. Hovering your avatar shows who is signed in on the server and which client each person is using.

File watchers and uploads

Each add-on export has its own switch. Turning one off stops that file from being uploaded; the others continue. The status line tells you whether the watcher is active and when it last saw a change.

The folder GuildSync watches is shown in User Settings. Change it there if your ESO documents folder is somewhere unusual, for example a Steam or Proton prefix on Linux.

Receipt mail is different. When GuildSync needs to write a queued receipt-mail batch, close ESO completely, let GuildSync write the batch, then reopen ESO to send it. Roster, banking and application uploads just need a /reloadui, logout or exit.

Voice mute shortcut

Where an administrator has enabled voice mute and chosen the roles it applies to, the desktop client can hold Ctrl+M to mute lower-ranked members in your current Discord voice channel. Releasing the keys, or leaving the channel, ends the mute. Moderator mutes are never undone.

You can assign a different mute key, plus a second unmute key that ends a mute immediately, in Voice. Pressing the mute key again restarts the countdown.

Updates

GuildSync checks the newest release about every six hours. When an update exists, the profile menu offers Download latest GuildSync: it downloads the installer for your platform and hands it to your operating system. Development builds skip the check.

If the server stops supporting your client version, GuildSync hides member and banking data and shows an unsupported desktop screen with the same download button. Install the update and restart.

Guild Chat on the desktop

Guild Chat opens in your web browser from the desktop client, so it keeps its own window and you can leave it open beside ESO. In the web client the same chat appears inside the Guild Chat tab.
